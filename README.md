## Features

* Crops, drying, fermentation and distillation.
* Drinks, smoking equipment and configurable drug effects.
* World deformation, hallucinations and configurable visual and audio effects.

Based on [DrugsNotIncluded's continuation](https://github.com/DrugsNotIncluded/Psychedelicraft-Legacy). Angelica integration is under development. Replaces other Psychedelicraft jars; the mod ID remains `psychedelicraft`.

## Dependencies

* [IvToolkit 1.2.1](https://www.curseforge.com/minecraft/mc-mods/ivtoolkit) [![curse](images/icons/curse.png)](https://www.curseforge.com/minecraft/mc-mods/ivtoolkit) [![git](images/icons/git.png)](https://github.com/Ivorforce/IvToolkit)

## Building

```sh
./gradlew build
```
